# Typography

Evangelion's UI was set in commercial typefaces: an ultra-condensed heavy
grotesk close to _Helvetica Condensed / Compressed_ for Latin text, and
_Matisse EB_ (Fontworks) for the Japanese headings. The original fonts were not
identified with certainty; these choices are free, OFL-licensed look-alikes
picked by comparing them with the reference frames.

## Loading the fonts

The tokens only reference family names. Both font files below register **the
same family names and weights**, so you load exactly one of them and nothing else
changes.

### Option A: embedded (default)

Self-hosted woff2 files, bundled with the library: works offline, no third-party
requests, no GDPR/privacy concern. The Google Fonts files come from the
[Fontsource](https://fontsource.org) packages, which repackage the exact Google
Fonts woff2 split by `unicode-range`. The Japanese fonts are therefore cut into
~120 slices, and a page only downloads the ones it uses. DSEG7 is vendored in
`src/lib/fonts/dseg7-classic`.

```css
@import "./src/lib/styles/nerv.css"; /* = fonts.embedded.css + tokens.css */
```

### Option B: Google Fonts CDN

```css
@import "./src/lib/styles/fonts.google.css";
@import "./src/lib/styles/tokens.css";
```

Or skip the CSS import and put the `<link>` tags in your HTML, which is faster
because the browser can start fetching before your CSS is parsed:

```html
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
<link
  rel="stylesheet"
  href="https://fonts.googleapis.com/css2?family=Antonio:wght@400;700&family=Archivo+Narrow:wght@400;700&family=Barlow+Condensed:wght@500;700;800;900&family=Noto+Serif+JP:wght@900&family=Oswald:wght@500;700&family=Shippori+Mincho+B1:wght@800&family=VT323&display=swap"
/>
```

DSEG7 is not on Google Fonts. `fonts.google.css` loads it from jsDelivr
(`dseg@0.46.0`). With the `<link>` approach, declare it yourself or import
`fonts.google.css` anyway.
