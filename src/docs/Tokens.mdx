# Tokens

All tokens are CSS custom properties prefixed with `--nerv-`, defined in
`src/lib/styles/tokens.css`. They are plain CSS, so they work the same in React,
in web components (custom properties go through shadow DOM boundaries) and in
plain HTML.

```css
@import "./src/lib/styles/nerv.css"; /* tokens + self-hosted fonts */
```

(Repository paths. Package entry points will be added with the library build.)

The primitive colours were **sampled from the reference frames** (see
`docs/REFERENCE.md`). The frame numbers are in the notes below each swatch. The
frames come from compressed video, so the values were picked from the brightest
part of each colour rather than averaged, which would give muddy results.

## Glow

Screens in the show glow like CRT phosphor. Glow tokens are lists of shadows
that use `--nerv-glow-color`, which defaults to `currentColor`, so they work with
both `text-shadow` and `box-shadow`.

<TokenTable
  tokens={["--nerv-glow-sm", "--nerv-glow-md", "--nerv-glow-lg"]}
  preview={(t) => (

Hazard stripe colours and size can be overridden locally:

```css
.caution {
  --nerv-hazard-a: var(--nerv-yellow);
  --nerv-hazard-size: 0.75rem;
  background: var(--nerv-pattern-hazard);
}
```
